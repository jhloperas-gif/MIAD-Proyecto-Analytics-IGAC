# Anteproyecto de Analytics — Registro de Transacciones Inmobiliarias (IGAC)

Proyecto académico de la Maestría en Inteligencia Analítica de Datos (MIAD), Universidad de los Andes.

## Objetivo
Explorar los registros inmobiliarios de Bogotá D. C. y Cundinamarca, de 2015 a 2023, para caracterizar y priorizar patrones registrales atípicos mediante técnicas descriptivas y de aprendizaje no supervisado. Los resultados analíticos no constituyen por sí mismos evidencia de irregularidades.

## Alcance de los datos
Se analiza un subconjunto del Registro de Transacciones Inmobiliarias del IGAC correspondiente a Bogotá D. C. y Cundinamarca (2015–2023). Los análisis registrales abarcan 2015–2023; los análisis monetarios deben considerar la cobertura de la variable `VALOR` y su ventana metodológica.

## Uso académico y privacidad
Este repositorio contiene documentación, resultados agregados y, cuando esté revisado, código para reproducir análisis. No se publicarán bases completas ni datos personales sin verificar previamente las condiciones de reutilización; tampoco se publicarán contraseñas, claves o tokens.
